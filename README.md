## fast-run (retired)

`fast-run/fast-run.sh` was the one-command Docker Compose evaluation install for the 1.x layout. It is
retired: the services, host names and images it wired up no longer exist, and the script now prints a notice
and exits. Its compose file stays for reference only.

Run cvhome locally with the `lcl` stack runner in a `cvhome` checkout instead:
**https://cvhome-saas.github.io/development/local-development**
